## Suggested Order

1. 先做 GPU resident candidate route buffer，并让 SPA / VPG 消费 buffer RID，不再依赖 `candidate_voxel_regions_by_asset` 的正常路径读回。
2. 将 VPG 的 `scene_field` / `collision_field` 输入改为借用 SV resident buffers，并把 stamp 输出限制为 compact dirty ranges。
3. 将 accepted placement 写回改为 batched command buffer 或 GPU allocator pass，减少 CPU per-object `spawn()`。
4. 接入 per-voxel object refs + `SceneVoxelTile` ranges 的 GPU same-type exclusion。
5. 把 heightfield fitting accepted output 接到同一套 GPU runtime / source write 路径，CPU 节点实例化降级为 debug view。
